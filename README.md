# NewCool CAJ - Asistencia Juridica

Portal educativo sobre la Corporacion de Asistencia Judicial de Chile.

## Demo

[https://caj.newcool.io](https://caj.newcool.io)

## Caracteristicas

- Informacion sobre asistencia juridica gratuita
- Calculadora de mediacion familiar
- Ubicacion de oficinas CAJ por region
- Guia de tramites legales
- Servicios de orientacion juridica

## Tecnologias

- Next.js 15
- React 19
- Tailwind CSS 4
- TypeScript

## Desarrollo

```bash
npm install
npm run dev
```

## Parte del Ecosistema NewCool

Este modulo es parte de [NewCooltura Informada](https://informada.newcool.io) - Portal de instituciones publicas de Chile.
